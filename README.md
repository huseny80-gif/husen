## 🚀 خطوات التثبيت والتشغيل

### الخطوة 1: إنشاء مشروع Supabase

1. اذهب إلى [supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً
2. اختر اسم المشروع وكلمة مرور قوية لقاعدة البيانات
3. انتظر حتى يكتمل الإعداد (~2 دقيقة)

### الخطوة 2: تشغيل سكربت SQL

في **Supabase Dashboard → SQL Editor**، انسخ محتوى الملف:
```
supabase/migrations/001_initial_schema.sql
```
والصقه ثم اضغط **Run**.

ثم شغّل ملف البيانات التجريبية:
```
supabase/seed.sql
```

### الخطوة 3: الحصول على مفاتيح API

في **Supabase Dashboard → Settings → API**:
- `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
- `anon public key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### الخطوة 4: إعداد متغيرات البيئة

```bash
cp .env.local.example .env.local
```

عدّل `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### الخطوة 5: تثبيت المكتبات وتشغيل المشروع

```bash
npm install
npm run dev
```

افتح المتصفح على: **http://localhost:3000**

## تحديث إدارة الاختبارات

بعد جلب التحديث، شغّل `supabase/migrations/002_instructor_quiz_management.sql`
في SQL Editor لمشروع Supabase الخاص بهذه المنصة. لا تعِد تشغيل الترحيل الأول
على قاعدة بيانات موجودة. الترحيل الثاني يضيف قراءة مسودات اختبارات مواد المدرب
ولا يغيّر صلاحية القراءة للطلاب.

من لوحة المدرب: اختر المادة ← إدارة الاختبارات والأسئلة داخل الفصل ← إضافة اختبار.
يُحفظ الاختبار كمسودة. أضف أسئلة بأربعة خيارات، وحدد الإجابة والدرجة والتفسير،
ثم انشر الاختبار من قائمته. يمكن إيقافه لإجراء التعديلات.
لا تَعُدّل اختبارًا سبق أن أجاب عنه الطلاب إن كنت تحتاج إلى الحفاظ على تطابق
نتائجهم مع الأسئلة الأصلية؛ أنشئ اختبارًا جديدًا في هذه الحالة.

لا يتطلب التحديث تغيير `.env.local`. التطبيق يستخدم صلاحيات Supabase الحالية،
ولا يحتاج إلى مفتاح `service_role`.

## مصادر الفصول وتوليد الاختبارات (التحديث 004)

1. طبّق `supabase/migrations/004_learning_sources.sql` في مشروع Supabase نفسه؛ لا تعِد تشغيل 001.
2. شغّل `npm install` بعد تطبيق التحديث.
3. أضف `OPENAI_API_KEY` كمتغير **خادم** في Vercel ثم أعد النشر. لا تستخدم بادئة NEXT_PUBLIC ولا تضع المفتاح في GitHub أو المحادثة. اختياريًا `OPENAI_MODEL`؛ الافتراضي `gpt-4.1-mini`. اشتراك ChatGPT لا يوفر رصيد API تلقائيًا.
4. من لوحة المدرب يمكنك إضافة مادة لمرحلة موجودة؛ تُسند المادة الجديدة إلى حسابك في معاملة واحدة، ويُرفض الاسم المكرر داخل المرحلة.
5. داخل المادة أنشئ فصلًا، ثم «إدارة الاختبارات والأسئلة» ← «محتوى الفصل وإنشاء اختبار من المصدر». ارفع PDF حتى 25 MiB أو أدخل نصًا حتى 40 ألف حرف. المصادر خاصة بالمدرب أو المسؤول، وليست مكتبة قراءة عامة للطلاب في هذه النسخة.
6. اختر مصدرًا و1–10 صفحات PDF و1–10 أسئلة؛ للنص الصفحة 1 فقط. وافق على إرسال المحتوى إلى OpenAI ثم ولّد. يرسل الخادم مقتطف PDF يحافظ على صور الصفحات والمعادلات؛ لا يرسل الكتاب كله. وثائق الخدمة: https://developers.openai.com/api/docs/guides/file-inputs
7. راجع الأسئلة والخيارات والحلول والاقتباسات وأرقام صفحات PDF الأصلية. النموذج مقيد بالمصدر بالتعليمات، والتحقق البرمجي يرفض البنية والمراجع غير الصالحة، لكنه **لا يثبت صحة الحل أو صحة الاقتباس دلاليًا**؛ المراجعة البشرية إلزامية قبل الحفظ والنشر. إذا لم يكف المصدر، قلل عدد الأسئلة.
8. سمّ الاختبار، وأقرّ بمراجعته ثم احفظه كمسودة. انشره من القائمة بعد مراجعة إدارة الأسئلة. الحفظ ذري: إما الاختبار وجميع أسئلته ومراجعه أو لا شيء. عند خطأ شبكة غير واضح افحص قائمة الاختبارات قبل تكرار الحفظ.
9. حدد التوليد بطلب كل دقيقة و20 طلبًا يوميًا لكل حساب مدرب. أخطاء API أو عدم كفاية المصدر قد تستهلك محاولة من الحد اليومي.

### المعادلات والتغذية الراجعة

تدعم نصوص الأسئلة والخيارات وشروح الحل LaTeX داخل `\( ... \)` أو `$$ ... $$` وكتابة الكيمياء مثل `\( \ce{CH4 + 2O2 -> CO2 + 2H2O} \)`. تعرض الرموز غير الصالحة كنص بدل إسقاط الصفحة. تعرض التغذية الراجعة لكل إجابة بعد التسليم، بما فيها الصحيحة، مع مصدر الصفحة للأسئلة المولدة.

### حدود النسخة الحالية

- الأنواع التفاعلية المدعومة: اختيار متعدد وصح/خطأ، بما في ذلك مسائل أو قواعد أو إعراب بصيغة اختيار إجابة.
- المطابقة والترتيب والفراغات والإجابات المفتوحة والتصحيح الآلي للإعراب الحر لم تُنفّذ بعد.
- رفع كتاب في محادثة ChatGPT لا يرفعه تلقائيًا إلى المنصة؛ ارفعه من واجهة الفصل بعد تطبيق 004.
- لا يُعاد توليد معادلات غير مقروءة على أنها حقائق مؤكدة. راجع المعادلات والوحدات والإشارات والصفحات الأصلية.
- لم يُغيَّر نظام تصحيح المحاولات السابق إلى نظام امتحانات آمن ضد التلاعب؛ يبقى تقوية التصحيح وحماية مفاتيح الإجابات عملًا منفصلًا قبل استخدامه لامتحانات رسمية.
